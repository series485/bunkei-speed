# 文型一閃（独立試作版）

文型道場の見た目と文型カードを受け継いだ、1台で遊ぶ早出し対戦ゲームです。公開先とファイルは文型道場とは別です。

## 起動

`index.html` をブラウザで開いてください。外部ライブラリ、ログイン、対戦通信は不要です。音はブラウザの仕様に合わせて初期状態ではOFFです。上部の「♪」を押すとBGMと効果音が鳴ります。

## ルール

- 1台の端末で2人対戦、またはCPUと対戦。場は1面／2面、制限時間は20秒／40秒／60秒から選択できます。初期設定は40秒です。
- 各プレイヤーの手札は常に4枚。出したカードは自動で補充されます。
- 手札を選んでから、手元側の置き先を押します。中央の場に触る必要はありません。
- 正しいカードは10点、英文を完成させた人に追加30点。文法上置けないカードは15点減点と0.7秒待機です。
- 双方に出せる手がないときは場を自動で流します。場を隠して「3、2、1」をそれぞれ0.5秒表示し、約1.5秒後に再開します。カウント中は手札と置き先を操作できません。
- 制限時間が尽きたとき、得点の高い方が勝ち。同点ならお手つきの少ない方が勝ちです。開始演出と場流し中の約1.5秒は時間に含みません。
- 各人の得点を60秒換算し、文型道場と同じ「文型見習い」「文型弟子」「文型師匠」「文型師範」の称号を付けます。称号判定では負点を0点として扱います。勝敗は換算前の対戦得点で決めます。

| 称号 | 60秒換算の得点 |
| --- | ---: |
| 文型師範 | 350点以上 |
| 文型師匠 | 250〜349点 |
| 文型弟子 | 150〜249点 |
| 文型見習い | 0〜149点 |

文型道場とは得点の計算方法が違うため、称号の基準点は文型一閃向けです。師範を取ると、結果画面に桜の花びらが舞い、専用BGMが流れます。
開始の「いざ尋常に…／参る！」と終了のふすま・「そこまで！」は文型道場の演出に合わせています。

## PCのキー

| 操作 | プレイヤー1 | プレイヤー2 |
| --- | --- | --- |
| 手札1〜4 | A・S・D・F | H・J・K・L |
| 置き先 S・V・O/C・O₂/C | Q・W・E・R | Y・U・I・O |
| 1面／2面の切り替え | G | セミコロンキー |

カードキー、置き先キーの順番に押してください。同時押しは不要です。CPU戦ではプレイヤー2側のキーは使いません。

## 試作段階の範囲

- 英文は第1〜第5文型に対応し、主語に応じた動詞変化、代名詞の目的格と再帰形を表示します。動詞は1枚につき主な文型を1つに絞っています。
- 文法上成立するが意味が少し奇妙な文は許容します。和訳や細かい解説は、早出しのテンポを優先して今回は表示していません。
- スマホの2人対戦では、端末を挟んで向かい合う配置を想定しています。上側のプレイヤー2の手札・ボタン・得点表示は180度回転し、場の各枠にも反対側から読める表示を加えています。両者の置き先ボタンを縦に大きくしています。実機での二人同時タッチの確認は今後必要です。
